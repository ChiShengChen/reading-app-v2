# 逐段翻譯閱讀器

把整篇文章貼進去（或開 .txt / .md / **.pdf** / **.epub** 檔），自動一段一段翻譯，用「譯文 + 原文對照」的方式好好閱讀。手機和電腦都能用。

## 啟動

```bash
python3 server.py        # 預設埠 8765,也可以 python3 server.py 9000
```

啟動後：
- 電腦開 **http://localhost:8765**
- 手機連**同一個 Wi-Fi**，開終端機顯示的那個 `http://192.168.x.x:8765` 網址

不需要 API key（翻譯走 Google 翻譯的免費網頁介面）。翻譯與 EPUB 解析只用 Python 標準庫；**讀 PDF 需要 PyMuPDF**（沒有的話 `pip install pymupdf`，也相容 pypdf）。

## 功能

- **支援格式**：貼上文字、.txt / .md，以及 .pdf（自動接回被硬換行切開的句子、還原連字號斷詞）和 .epub（依章節順序抽出內文）
- **自動分段**：以空行分段；沒有空行就按換行分；過長的段落自動按句子切開
- **逐段翻譯**：邊翻邊顯示進度，翻好的段落立刻可以讀
- **三種閱讀模式**：對照（譯文+原文）／只看譯文／只看原文
- **翻譯快取**：翻過的段落存在瀏覽器裡，同一篇文章下次秒開
- **失敗重試**：某段失敗會標紅，點一下該段就重試
- **閱讀體驗**：字體大小調整（A− / A＋）、深淺色切換（◐）、手機直向排版
- **語言**：來源語言自動偵測；目標語言可選繁中、簡中、英、日、韓、法、德、西
